## Funcionalidades

- Dinossauro pixelado e animado
- Movimento de pulo com gravidade
- Dinossauro pode se abaixar
- Cactos e passaros como obstaculos
- Deteccao de colisoes
- Pontuacao e dificuldade progressiva
- Recorde salvo em JSON
- Ciclo de dia e noite
- Lua, estrelas e estrelas cadentes decorativas
- Efeitos sonoros gerados pelo Python
- Tela de Game Over e reinicio

---

## Controles

| Tecla | Funcao |
|---|---|
| ESPACO / SETA CIMA / W | Pular |
| SETA BAIXO / S | Abaixar |
| M | Ligar ou desligar som |
| N | Alternar dia e noite |
| T | Voltar ao ciclo automatico |
| P | Pausar |
| R | Reiniciar apos Game Over |

## Como instalar e executar

### 1. Clone o projeto

```bash
git clone https://github.com/samuelcmaggi/chrome-dino-python.git
cd chrome-dino-python
```

### 2. Instale a dependencia

```bash
pip install -r requirements.txt
```

### 3. Execute

```bash
python dino.py
```

No Windows com Python 3.13:

```powershell
py -3.13 dino.py
```
